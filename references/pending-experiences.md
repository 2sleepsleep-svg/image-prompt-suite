# 待确认与待验证经验

## 使用方式（2026-11-14 用户授权）

用户明确要求把不确定或有冲突的经验留作后续测试。用户提出提升技能、做测试或验证外部技巧时，主动读取本文件，挑选与当前模型、素材、任务和预算有关的候选，提供完整提示词、实际输入、全部差异及观察标准。待确认是“效果待验证”，不是已生效默认规范；不覆盖既有用户约定，不自动生成或付费。

保留来源、疑点、适用条件、测试版本、回传与副作用；采用“待实测／待事实核验／本组观察／条件性支持／不稳定／未检出优势”等状态。一次可用不等于跨模型通用。已有相同经验只补来源和结果；对照按问题合并，不默认扩大矩阵。转为默认经验仍按主文件的确认流程。

| HI04 组合预检 | 资产组合预检是否减少后续视频返工 | 在获准实际项目中记录有无代表性组合预检的成本及后续缺陷；不同场景难度须说明 | 面部高光、环境光、材质、身份与总成本；静帧不能验证运动和表演，不强制增加制图 |

| HI06 细条纹与过曝 | 作者将塑料肤质与额头过曝、衣服问题与细条纹关联 | 遇到同难点时比较经修正资产与原合格基准，保持其余条件可比；不制造错误基准 | 高频纹理漂移、脸部高光、身份和目标服装保留；归因可能受光线／模型等共同影响 |
| HI07 场景三分之四角度 | 斜向展示更多布局是否比正面图更利于跨机位 | 同空间同光线，以相同后续镜头任务比较不同展示视图 | 布局、遮挡后结构及换机位连续；不是所有场景必须斜拍，不把不同布景当角度实验 |
