# 提示词约束回归案例

用于修改规则后的行为检查，非日常交付模板。2026-11-17建立；案例尚未在独立新对话中执行，不能声称已验证跨对话稳定性。

测试时在独立上下文中提供技能、下列情境和请求，不提供评判栏或本次纠错对话。无需生成图片，检查实际提示词及其输入分工。多轮案例按顺序发送，不将所有历史错误只写成最后一条提醒。

|案例|给被测助手的情境与请求|评判要点|
|---|---|---|
|格式切换|此前要求四宫格分镜；现在要求从零写一张单幅窗边阅读照片的GPT提示词，不上传旧宫格。|正文描述当前照片；不带旧宫格引用或自动附加“不使用四宫格／不分格”；保留仍有效人物与场景要求。|
|无依据排除|写一张咖啡馆女士休息的GPT广告图片提示词，简洁自然，没有参考图和出图失败记录。|不凭“广告”自动加无字幕、无Logo、无水印等尾句；不为了回避负面词而添加正向同义限制。|
|必要排除|用户明确要求照片中不要文字；后一轮只把人物动作从阅读改成喝咖啡。|保留文字排除要求，准确改变动作，不把局部修改当成重置全部条件。|
|当前偏差|用户反馈上一张确实生成了多余字幕，要求重写提示词纠正，其他要求保持。|针对字幕处理，不扩成无Logo、无边框等无依据清单；不因避免负面提示而忽略实际问题。|
|中文交付|用GPT写女士看窗外的图片提示词。|遵守已保存的中文默认；无重复中文对照表；如后续明确要求英文，则给英文正文及中文对照。|
|局部修改|已有提示词锁定蓝衣、阴天、窗边坐姿，用户仅要求把手中杂志改成咖啡。|保留蓝衣、阴天与坐姿，只改持物动作及必要联动；不以清理旧限制为由全文改写。|

评判以语义为准：排除句的出现或缺席本身不是通过标准，要核对来源、有效范围及用户目标是否保留。记录技能版本、实际输出、失败位置和运行条件；文档结构校验、人工审稿、独立行为测试与图像生成验证分别报告。
